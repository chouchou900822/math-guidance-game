# 数学冒险乐园

给 6–9 岁孩子的数学闯关小游戏：先在 **乘法星球** 背熟 45 句九九乘法口诀，再到 **除法森林** 用口诀把果子平均分。每天玩 10 分钟左右，打开浏览器就能用。

整个项目是纯静态网页：零依赖、无需构建、没有后端，也不用注册账号，学习进度只保存在本机浏览器里。

## 两个游戏

| | 第 1 站 · 乘法星球 | 第 2 站 · 除法森林 |
| --- | --- | --- |
| 学什么 | 表内乘法：9 颗星球对应 1–9 的乘法表，共 45 句口诀 | 表内除法：9 家小动物对应 ÷1–÷9，共 81 道除法 |
| 怎么学 | 用点阵看懂「几个几」，听口诀朗读，点读整张九九表 | 动手把果子平均分，再用乘法口诀求商，点读整张除法表 |
| 题型 | 求积、补全缺少的因数 | 求商、找除数、找被除数，以及「平均分」「每份几个、能分几份」两种图画题 |
| 奖励 | 攒星星，兑换星球皮肤（共 10 款） | 攒松果，种下大树（共 10 棵） |
| 终点 | **1024 号空间站**：把 1 翻倍十次，2¹⁰ = 1024 | **1024 丰收节**：把 1024 对半分十次，剩下 1 |
| 入口 | [`multiplication-planet/`](multiplication-planet/index.html) | [`division-forest/`](division-forest/index.html) |

### 为什么先乘后除

除法用的就是乘法口诀。在乘法星球背熟「三四十二」，到了除法森林，12 ÷ 3 和 12 ÷ 4 马上就能想出来——一句口诀，能算三道题：

> 三四十二 → 3 × 4 = 12，12 ÷ 3 = 4，12 ÷ 4 = 3

## 功能一览

- **闯关**：可选 1–5、6–9、1–9 三档范围，每关 10 道四选一的题，也能用键盘数字键 1–4 作答。正确率达到 50%、70%、90% 分别评 1、2、3 星。
- **错题巩固**：答错的题会进入「待巩固」，连续答对两次才算掌握，可以单独重练。
- **每日挑战**：用当天日期当随机种子生成 8 道题，同一天打开都是同一套题；每天第一次完成有额外奖励，并记录连续天数。
- **奖章墙**：每个游戏各 16 枚奖章，比如答满 100 题的「百题斩」、连续练习 7 天的「七日不辍」。
- **互动彩蛋**：轻点、长按星球或大树都有互动，还藏着需要长按才能唤醒的彩蛋。
- **终局关卡**：九张表全部拿到三星后解锁，10 道题答对 8 道即通关，首次通关奖励限定的「1024 灯塔」星球皮肤 /「丰收金树」。
- **家长学习报告**：最近 7 天的练习量和正确率、九张表各自的掌握情况、需要巩固的题目和练习建议；可以打印或存为 PDF，也可以一键清空学习记录（星星 / 松果、皮肤 / 大树不受影响）。
- **中文朗读与音效**：口诀用浏览器自带的语音合成朗读，音效用 Web Audio 实时合成，可以随时关闭声音。
- **演示模式**：在游戏地址后加 `?demo=1`，直接解锁全部皮肤 / 大树和终局关卡，并预置最近一周的示例学习记录，方便查看报告；演示中的操作不会保存。
- **门户页**：根目录的 `index.html` 是两个游戏的入口，卡片上会显示孩子在这台设备上的闯关进度。

## 快速开始

不需要安装依赖，也没有构建步骤。在仓库根目录启动任意静态文件服务器即可，例如：

```bash
python3 -m http.server 8000
```

然后用浏览器打开 <http://localhost:8000/>。也可以直接用浏览器打开根目录的 `index.html` 快速预览。

| 地址 | 内容 |
| --- | --- |
| `/` | 门户页 |
| `/multiplication-planet/index.html` | 乘法星球 |
| `/division-forest/index.html` | 除法森林 |
| 游戏地址加 `?demo=1` | 演示模式（不保存任何操作） |

两个游戏都支持用 URL hash 直接打开某个页面，例如 `multiplication-planet/index.html#report`：

| hash | 页面 |
| --- | --- |
| `#learn-1` … `#learn-9` | 第 1–9 张表的学习页 |
| `#grid` | 整张九九表 / 除法表 |
| `#shop` | 星球皮肤 / 大树苗圃 |
| `#awards` | 奖章墙 |
| `#report` | 家长学习报告 |
| `#about` | 关于这个作品 |
| `#station` / `#harvest` | 1024 号空间站（乘法星球）/ 1024 丰收节（除法森林） |

## 部署

全部是静态文件，把仓库根目录原样发布到任意静态托管即可（GitHub Pages、Netlify、Vercel、Nginx 等）。以 GitHub Pages 为例：在仓库 **Settings → Pages** 中把 Source 设为 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`。

## 目录结构

```text
.
├── index.html                  # 门户页：两个游戏的入口与本机进度
├── portal/                     # 门户页的样式与脚本
├── multiplication-planet/      # 乘法星球
│   ├── index.html
│   ├── css/                    # 基础层、页面层、空间站、学习报告、每日挑战与奖章墙、关于页、彩蛋
│   └── js/
│       ├── app.js              # 状态、路由与交互控制
│       ├── app-actions.js      # 界面动作表
│       ├── base/               # 音效与中文朗读、图标与装饰层
│       ├── data/               # 口诀与出题、本地存档与迁移、每日挑战、学习统计、演示数据
│       ├── screens/            # 首页、学习页、闯关、皮肤、奖章墙、口诀朗读
│       ├── panels/             # 1024 号空间站、家长报告、奖章判定、关于页
│       └── planet/             # Canvas 3D 星球、程序化纹理、皮肤彩蛋特效
└── division-forest/            # 除法森林，分层与乘法星球相同
    ├── index.html
    ├── css/                    # 其中 forest.css 负责树屋场景、平均分、图画题与丰收节
    └── js/                     # 其中 panels/harvest.js 是终局「1024 丰收节」
        └── forest/             # SVG 树屋场景、小动物与果子、大树彩蛋
```

## 技术说明

- **零依赖**：原生 HTML、CSS 和 JavaScript，没有框架、构建工具或第三方库，不加载任何外部资源，也不发网络请求；字体使用系统自带的中文字体。
- **脚本组织**：用普通 `<script>` 标签（不是 ES Module）按 `index.html` 里的顺序加载。每个 JS 文件是一个立即执行函数，通过全局命名空间互相调用——乘法星球是 `window.MP*`，除法森林是 `window.DF*`。新增文件时要在 `index.html` 中按依赖顺序引入。
- **路由**：打开页面时根据 URL hash 决定显示哪一屏，切换页面时同步更新 hash。
- **图形全部由代码生成，没有一张图片**：乘法星球的星球是在 Canvas 上逐像素软渲染的 3D 球体（程序化纹理 + 预先算好的球面投影查找表）；除法森林的树屋、小动物和果子都是按参数拼出来的 SVG。
- **声音**：音效由 Web Audio API 实时合成；口诀朗读使用 `speechSynthesis`，优先选用中文（zh-CN）语音，浏览器不支持时会自动跳过。
- **存档**：每个游戏只用一个 localStorage 键（`multiplication-planet-v1`、`division-forest-v1`），载入时会迁移并校验旧版本的字段（`js/data/store-migrate.js`）。门户页只读这两个键；修改存档字段时，记得同步检查 `portal/portal.js`。
- **两个游戏结构相同**：目录分层和大多数模块一一对应，修改存档、报告、奖章、每日挑战等通用逻辑时，注意两边保持一致。
- **无障碍**：所有按钮都能用 Tab 键到达，答题可用数字键 1–4，键盘焦点有醒目的描边，并会遵循系统的「减少动态效果」设置（`prefers-reduced-motion`）。
- **本机实测**：「关于」页可以在当前设备上实测渲染耗时。

## 隐私

- 不注册、不登录，没有后端，不上传任何数据。
- 没有广告、内购、第三方脚本和埋点。
- 学习记录只保存在当前设备的浏览器里；换设备或清除浏览器数据后，进度不会保留。
- 演示模式只在内存中运行，不写入存档。
